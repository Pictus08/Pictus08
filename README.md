# Hola, soy Pablo Luis Quiñones

### Ingeniería civil · Automatización · Herramientas digitales

Soy ingeniero civil de Misiones, Argentina. Actualmente gestiono canteras y plantas de trituración, estabilizado y asfalto. Mi trayectoria también incluye proyectos hidráulicos y modelado BIM de instalaciones.

Me interesa conectar la experiencia de campo con la programación: automatizar tareas, trabajar con datos y desarrollar herramientas útiles para la ingeniería y la producción.

## Proyecto destacado

### [Generador de hidrogramas para SWMM](https://github.com/Pictus08/Archivo_DAT_Hidrograma_Triangular-C-)

Programa en **C++** para generar hidrogramas de caudal a partir de parámetros de entrada y exportar los resultados a un archivo **DAT** que puede utilizarse como serie de datos en SWMM.

Un punto de encuentro entre hidráulica y programación.

## Mi base técnica

- **Ingeniería:** producción de agregados, gestión de canteras y plantas, mantenimiento y proyectos hidráulicos.
- **BIM y diseño:** AutoCAD, Revit y Navisworks; automatización visual con Dynamo y Grasshopper.
- **Programación aplicada:** Python para automatizar procesos de ingeniería y Excel/VBA para tareas de oficina técnica.
- **Desarrollo web:** JavaScript y Next.js; formación complementaria en React, Node.js, SQL y MongoDB.
- **Hidráulica y territorio:** QGIS y formación en EPANET, SWMM, HEC-RAS y SWAT+.
